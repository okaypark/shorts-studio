# 화면 규칙

이 문서는 "이렇게 생겨야 한다"가 아닙니다. 영상마다 얼굴은 달라야 합니다.
여기 적힌 건 **어떤 컨셉으로 가든 깨지면 안 되는 것**들뿐입니다.

## 읽히는가

- 한글 텍스트에는 `korean` 을 펼쳐 넣습니다. 안 하면 단어 중간에서 줄이 끊깁니다
- 화면 큰 글씨는 12자 이내, 두 줄까지. 넘으면 문장을 자릅니다
- 배경 위에 글자를 얹을 때는 반드시 대비를 확보합니다 — 어두운 막을 덮거나, 글자에 그림자를 주거나, 글자 자리를 비운 사진을 씁니다
- 자막은 한 영상 안에서 **같은 자리**에 옵니다. 위치를 옮기면 시선이 매번 자막을 찾아야 합니다

## 가려지지 않는가

- 세로 영상은 위아래를 플랫폼 UI가 덮습니다. `SAFE_AREA`(위 220px, 아래 380px) 안쪽에 중요한 걸 두세요
- 자막이 하단 UI에 물리지 않는지 확인합니다

## 시간이 맞는가

- 장면 하나가 3초 미만이면 읽을 시간이 없습니다
- 8초를 넘으면 둘로 나눕니다
- 자막 글자 수 ÷ 6.5 + 1초 가 최소 노출 시간입니다 (`readingSeconds()` 가 계산해 줍니다)

## 눈이 어디를 봐야 하는가

- 한 화면에 움직이는 요소가 셋 이상이면 아무데도 안 보게 됩니다
- 목록은 하나씩 차례로 등장시킵니다. 한꺼번에 나오면 어디부터 읽을지 알 수 없습니다

## 다양성 — 매번 새로 정하는 것

아래는 **영상마다 다르게 가져가야 하는** 항목입니다. 직전 영상과 같으면 다시 고르세요.

| 항목 | 선택지 예 |
|---|---|
| 정렬 | 가운데 / 왼쪽 / 아래에서 쌓기 / 대각선 |
| 배경 | 사진 + 스크림 / 단색 / 그라디언트 / 창고의 움직이는 배경(`grid-pulse`, `bokeh-circles`, `starfield`, `liquid-wave`) |
| 강조색 | 주제에 맞는 색 하나. 한 영상에 강조색은 하나면 충분합니다 |
| 글자 등장 | 스프링 상승 / 타이핑 / 글자별 팝 / 슬라이드 / 마스크 열림 |
| 전환 | 페이드 / 슬라이드 / 와이프 / 아이리스 / 줌 스루 |
| 구조 | 목록형 / 비교형 / 카운트다운형 / 인용형 / 데이터형 |

여섯 칸을 다르게 고르면 같은 주제라도 완전히 다른 영상이 나옵니다.
`videos/vitamin-d-morning` 과 `videos/desk-stretch-3` 이 그 예입니다 — 공유하는 게 하나도 없습니다.
